# Contribute

# Development

* Make sure to uphold the standards documented under _Features_ in the [README](./README.md).
* Format the code using [EditorConfig](https://editorconfig.org) in this repository.
* Write unit tests.
* Make atomic commits.
* Please comment commits according to [Conventional Commits](https://www.conventionalcommits.org).
* Make sure public interfaces and members are documented.
* Make sure the documentation (i.e. the README etc.) is up-to-date.


## Testing

* Use [NUnit](https://nunit.org) for unit testing.
* Use [FakeItEasy](https://fakeiteasy.github.io) for mocking.
* Use [Shouldly](https://docs.shouldly.org) for assertions.
* Apply the [Arrange-Act-Assert](https://martinfowler.com/bliki/ArrangeActAssert.html) pattern.


# Pull requests

* Rebase to the latest main before creating a pull request.
* Make sure all tests pass.
* Make sure all example projects run as intended.
* Please relate the PR to a GitHub issue.


# Release Process

This project adheres to the [Semantic Versioning](https://semver.org/) guidelines.
